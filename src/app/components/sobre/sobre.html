Sobre

Estou no 4º semestre de Análise e Desenvolvimento de Sistemas na UNIP, com formatura prevista para dezembro de 2026, e trabalho como estagiário de desenvolvimento de software.

Escrevo back-end em C# com ASP.NET Core e Entity Framework Core, e interfaces em Angular. Fora da faculdade e do estágio, faço projetos para clientes: um sistema de agendamento para a barbearia do meu irmão, uma landing page para uma loja de autopeças e um site para uma confeitaria.

Na faculdade, montei um sistema completo para uma ONG fictícia de adoção de animais, com API de 25 endpoints, SQL Server e um recomendador em Python.
